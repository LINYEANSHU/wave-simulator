科学说明

物理模型

本页模拟求解二维标量波动方程 ∂²u/∂t² = c²∇²u。u 可以理解为浅水槽表面波的位移，或声波某截面的声压。波源的叠加与干涉、遇到障碍的反射与衍射，都是方程解的自然结果，而非预设动画。

数值方法（FDTD）

显式二阶中心差分：

uⁿ⁺¹ = 2uⁿ − uⁿ⁻¹ + C²·(uₓ₊ + uₓ₋ + u_y₊ + u_y₋ − 4uⁿ)

其中 C = c·Δt/Δx 为 Courant 数。二维格点上稳定性要求 C ≤ 1/√2 ≈ 0.707，本页限制在 0.08–0.70。空间步长 Δx = 1 格，Δt = 1/180；「时间流速」按倍率推进子步（¼× 慢放便于观察衍射），波形与频率在所有流速下保持一致。

波源

采用软波源：每步在源区叠加 A·sin(2πft + φ₀) 源项，对外行波近乎透明。点源为高斯窗（σ ≈ 2 格），平面波源为竖直高斯条带。每个波源可独立设定初相位 φ₀：两源反相（相差 180°）即偶极辐射。脉冲工具向场注入一次高斯位移。多普勒场景中的波源以恒定速度往复运动，可观察前方波前压缩、后方疏张。

障碍与边界条件

反射墙内部格点每步强制 u = 0（狄利克雷硬边界），完全反射；吸波墙对墙内格点施加强速度阻尼，近似无反射软材料（消声尖劈的一维类比），可用于建造"安静"的屏障。外边界两种近似：

  • 吸收：边缘约 11% 区域设置立方渐变的速度阻尼"海绵层"（能量单调耗散）；是完美匹配层（PML）的简化替代，存在微弱残余反射。
  • 反射：最外一圈格点 u = 0，等效刚性壁，可观察驻波与腔内共振。

测量工具

探针：读取放置点的瞬时 u 并绘制实时波形；「实测频率」由去均值后的过零计数估计，可与设定频率对照：短波长（小 λ）时两者差异正是数值色散的直接体现。观察屏：读取屏线一列的时均强度 |u|²，以剖面形式贴附显示，即经典双缝实验中"屏上光强分布"的数值版本。强度场为 |u|² 的指数滑动平均（时间常数约 1.4 模拟秒）。

稳定性限制

当局部振幅异常增大（如反射腔共振累积）时，施加轻微非线性阻尼"软限幅"防止数值发散；正常幅度 |u| < 0.8 内严格线性。显示端采用 tanh 软压缩色调映射。

已知近似与局限

  • 数值色散：波长接近格距时相速度略偏慢，建议 λ ≥ 10 格（信息栏实时显示当前波长）。
  • 二维点源振幅按 ~1/√r 衰减（能量在 1/r 圆周上扩散），与三维的 1/r 不同。
  • 吸波墙为强阻尼近似，垂直入射吸收良好，掠入射仍有部分反射。
  • 真实水面重力波是非线性色散系统，此处为线性、非色散近似；定性现象（干涉、衍射、多普勒、拍）一致。

性能与隐私
